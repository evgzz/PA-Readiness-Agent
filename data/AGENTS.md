# Codex instructions — data

Preserve provenance, source case/family groups, split purpose, and dataset version.
Never put expected answers into the agent input record. Avoid training/evaluation
leakage through paraphrases or shared source cases. Keep qualification data and
private clinical evidence outside this repository and the agent's runtime mounts.
Do not claim synthetic generation establishes privacy or clinical validity for
arbitrary imported data. Review origin, rights, and release eligibility per asset.
